# Кастомные команды Banjoball 5x5

Все перечисленные ниже команды доступны только разработчику (Steam ID: `201230874`), либо в локальном лобби при включенных читах / в режиме инструментов (`Tools Mode`). Для обычных игроков в публичном лобби они отключены.

Каждая из команд может вводиться как в обычный игровой чат, так и непосредственно в консоль разработчика `~`.

---

## Доступные команды

### 1. Текущие координаты героя
* **Имя команды в чате:** `!pos` (или `-pos`, `pos`) | **в консоли:** `bb_pos`
* **Описание:** Выводит в игровой чат точные координаты вашего героя (`X`, `Y`, `Z`).
* **Пример:** `[POS] Player 0 | X=-1500.0 Y=2300.0 Z=128.0`

### 2. Получение Steam ID
* **Имя команды в чате:** `!steam` (или `-steam`, `steam`) | **в консоли:** `bb_steam`
* **Описание:** Выводит в игровой чат ваш Steam Account ID.
* **Пример:** `[STEAM] Player 0 | AccountID = 201230874`

### 3. Случайный выбор героев
* **Имя команды в чате:** `!random` | **в консоли:** `bb_random`
* **Описание:** Автоматически выбирает случайного героя всем игрокам и ботам, которые еще не выбрали героев, после чего принудительно завершает стадию драфта и мгновенно запускает игру.

### 4. Изменение счета игры
* **Имя команды в чате:** `!score <team> <score>` | **в консоли:** `bb_score <team> <score>`
* **Параметры:**
  * `<team>` — сторона: `left` / `radiant` / `blue` (для левой команды) или `right` / `dire` / `red` (для правой команды).
  * `<score>` — число (новое количество голов).
* **Описание:** Устанавливает количество голов для указанной команды, обновляет счет на верхней панели и в UI.
* **Пример:** `!score left 5` или `!score right 3`

### 5. Мгновенная победа
* **Имя команды в чате:** `!win <team>` (или `!win`) | **в консоли:** `bb_win <team>` (или `bb_win`)
* **Параметры:**
  * `<team>` (опционально) — сторона: `left` / `radiant` / `blue` (для победы левой команды) или `right` / `dire` / `red` (для победы правой команды). Если параметр опущен, побеждает команда игрока, вызвавшего команду.
* **Описание:** Завершает матч досрочно победой выбранной команды (или вашей команды).
* **Пример:** `!win left` или `!win`

### 6. Динамическое выполнение Lua-кода (Dev)
* **Имя команды:** `lua <код>` (только в чате)
* **Описание:** Выполняет произвольный Lua-код на сервере (доступно только при наличии прав в таблице разработчиков `SELID`).

### 7. Загрузка героев (Dev)
* **Имя команды:** `loadhe` (только в чате)
* **Описание:** Вызывает перезагрузку списка героев во внутренние структуры (доступно только при наличии прав в таблице разработчиков `SELID`).

---

## Вспомогательные консольные команды

* `play_sound <sound_name>` — проигрывает указанный звуковой файл на клиенте вызвавшего игрока.
* `phystest` — запускает тестовую функцию физического движка (требует читов).
